# Design Guideline — UniCanteen

## Цветовая палитра

| Назначение | Цвет | HEX |
|-----------|------|-----|
| Основной (primary) | Синий | `#2563eb` |
| Основной тёмный | Тёмно-синий | `#1e3a8a` |
| Основной светлый (bg) | Голубой | `#eff6ff` |
| Успех / готово | Зелёный | `#10b981` |
| Ошибка / отмена | Красный | `#ef4444` |
| Предупреждение | Жёлтый | `#f59e0b` |
| Текст основной | Тёмно-серый | `#111827` |
| Текст вторичный | Серый | `#6b7280` |
| Граница | Светло-серый | `#e5e7eb` |
| Фон страницы | Почти белый | `#f3f4f6` |
| Белый | Белый | `#ffffff` |

## Типографика

| Уровень | Размер | Вес |
|---------|--------|-----|
| Заголовок H1 | 28–36px | 700 |
| Заголовок H2 | 20–24px | 600 |
| Заголовок H3 | 16–18px | 600 |
| Тело текста | 14–15px | 400 |
| Мелкий текст | 12–13px | 400 |

**Шрифт:** системный (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`)

## Компоненты

### Кнопка (primary)
```css
background: #2563eb
color: #fff
border-radius: 8px
padding: 10–14px 20–32px
font-size: 14–16px
```

### Кнопка (danger)
```css
background: #ef4444
color: #fff
border-radius: 8px
```

### Карточка
```css
background: #fff
border: 1px solid #e5e7eb
border-radius: 12px
padding: 16–24px
```

### Поле ввода
```css
padding: 8–10px 12–14px
border: 1px solid #d1d5db
border-radius: 8px
font-size: 14–15px
```
