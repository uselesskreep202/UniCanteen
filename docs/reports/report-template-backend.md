## Выполненная работа (до 250 слов)

В рамках проекта UniCanteen я разработал серверную часть приложения на Python с использованием фреймворка FastAPI.

**Разработал следующие модули:**

**Модели данных (SQLAlchemy ORM):**
— `User` — пользователь с ролями student/staff/admin  
— `Category`, `Dish` — меню столовой  
— `Order`, `OrderItem` — заказы и позиции  
— `TimeSlot` — временные слоты получения  

**API эндпоинты (15+):**
— Аутентификация: регистрация, вход (JWT), просмотр профиля  
— Меню: CRUD для блюд и категорий  
— Заказы: создание, просмотр, смена статуса, отмена студентом  
— Слоты: создание и просмотр  
— Статистика: сводка по заказам для администратора  

**Архитектурные решения:**
— Repository Pattern — изоляция слоя доступа к данным  
— Service Layer — вынесена бизнес-логика (валидация слота, расчёт суммы)  
— Factory Pattern — создание сложного объекта Order в OrderService  
— Dependency Injection через FastAPI Depends  

**Безопасность:**
— JWT токены для аутентификации  
— bcrypt хеширование паролей  
— Ролевая авторизация (student/staff/admin)
