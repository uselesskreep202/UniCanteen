**DevOps:**  
Настроил CI/CD pipeline на GitHub Actions (`.github/workflows/ci.yml`). Pipeline включает три джобы: `backend` (lint + тесты + PostgreSQL сервис), `frontend` (lint + тесты), `docker` (проверка сборки образов). Все пуши в `main` и `develop` автоматически проходят проверку. Настроил PostgreSQL как сервис в CI для интеграционных тестов бэкенда. Также настроил структуру веток репозитория: защита `main`, обязательные PR в `develop`.
