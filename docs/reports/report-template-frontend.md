## Выполненная работа (до 250 слов)

В рамках проекта UniCanteen я разработал клиентскую часть приложения на React 18 с TypeScript.

**Реализованные страницы:**
— `HomePage` — главная с описанием сервиса и призывом к действию  
— `LoginPage` / `RegisterPage` — форма входа и регистрации  
— `MenuPage` — каталог блюд с фильтрацией по категориям  
— `CartPage` — корзина, выбор временного слота, оформление заказа  
— `OrdersPage` — история заказов с возможностью отмены  
— `StaffPage` — панель сотрудника (заказы + управление блюдами)  
— `AdminPage` — панель администратора (статистика, пользователи, слоты, категории)  

**Архитектурные решения:**
— Zustand — глобальное состояние (авторизация, корзина)  
— Axios с интерцепторами — автоматическое добавление JWT, обработка 401  
— React Router — клиентская маршрутизация с защитой роутов  
— TypeScript — типобезопасность, интерфейсы для всех API-ответов  

**Компоненты:**
— `Navbar` — навигация с ролевыми ссылками и счётчиком корзины  
— `DishCard` — карточка блюда с кнопкой добавления в корзину  
— `OrderStatusBadge` — визуальный индикатор статуса заказа  

**Тестирование:**
— Юнит-тесты Zustand сторов (cartStore, authStore)  
— Тест компонента OrderStatusBadge  
— Линтинг: ESLint (0 ошибок)
